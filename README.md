## Publicar en GitHub Pages

1. Crea un repositorio público llamado `portfolio` (o `TUUSUARIO.github.io`).
2. Sube `index.html`, `styles.css` y `script.js`.
3. En GitHub: **Settings → Pages**.
4. En *Build and deployment*, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`.
6. Guarda. GitHub te dará la URL pública.

## Antes de publicarlo

En `index.html` sustituye:

- `TU_EMAIL@ejemplo.com`
- `https://github.com/`
- `https://www.linkedin.com/`

por tus datos reales.

También conviene añadir los nombres exactos de empresas, fechas, enlaces a repositorios y capturas de proyectos que quieras hacer públicos.
